# CHANGELOG.md

## [1.2.0] — 2026-09-17

### נוסף
- זום תצוגה גלובלי (70%-150%) בסרגל הצד ובתפריט המובייל.
- חישוב "היום" לפי שקיעה בפועל (בהתאם לעיר שנבחרה בהגדרות) במקום חצות לועזי בלבד — כולל תיקון תזכורות פרישה שלא התחשבו בכך קודם.
- חישוב תאריך לידה משוער (280 יום מהווסת האחרונה), מוצג רק לאחר 35+ יום ללא הפסק, עם אזהרה מפורשת שזו הערכה בלבד.
- התראות מחשב/דפדפן (כבוי / יומי / רק ימי אירוע).
- בדיקת עדכון גרסה אוטומטית מול GitHub Releases + הורדה/התקנה מתוך התוכנה, כולל גיבוי בטיחות אוטומטי לפני התקנה (Electron בלבד).
- הפעלה אוטומטית עם המחשב + מזעור למגש המערכת בסגירה (Electron בלבד), כדי שהתראות ימשיכו להגיע.
- כניסה אוטומטית במסך הנעילה לאחר הקלדת הספרה השישית של קוד הגישה.
- קובץ `LICENSE` (GPL-2.0-or-later) ו-`README.md` מלא.

### תוקן
- מיקום שגוי של סימוני "נקיים" (היום הראשון) ו"טבילה" בלוח — כעת מוצגים בחלק העליון (לילה) של המשבצת הנכונה, בהתאם לכלל שהיום העברי מתחיל בלילה.
- אייקון כפתור העיצוב (יום/לילה) איבד את ה-SVG שלו והוחלף באימוג'י בכל טעינה/החלפה — הוחזר לאייקון SVG אמיתי (SUN/MOON).
- מחלקת `.alert-pulse` (אנימציית אייקון האזהרה בדשבורד) נקראה מהקוד אך לא הייתה מוגדרת כלל ב-CSS — נוספה.
- קובץ `icon.png` היה בפועל JPEG עם סיומת שגויה — הומר לקובץ PNG תקין.

### שונה
- כל שימושי האימוג'י בממשק הוחלפו באייקוני SVG עקביים.
- מרקרים בלוח השנה: צבעים שטוחים במקום גרדיאנט; הוסרה אנימציית הפעימה האינסופית על הבלטת "היום" (הוחלפה במסגרת סטטית).

## [1.1.1] — 2026-09-17

### תוקן
- אייקון SVG שבור (תג `<path>` לא סגור) בכפתור "ריכוז וסתות" — היה עלול לגרום לבעיות רינדור בסביבות מחמירות יותר.
- משתני CSS חסרים (`--shadow-lg`, `--surface-hover`) שגרמו לצל ורקע חסרים באפקט ה-hover בתצוגה השנתית ובכותרות החודש.
- קובץ `icon.png` לא נכלל בבנייה הארוזה של Electron, מה שגרם לאייקון חלון חסר בתוכנת הדסקטופ המותקנת.

### הוסר
- קוד מת: שני stub functions ריקים שלא היו בשימוש (`moveToNext`, `handleBackspace`).

### נבדק
- כל זרימות המשתמש המרכזיות אומתו ידנית בדפדפן חי (ללא שגיאות קונסול).
- תהליך האריזה המלא של Electron (`npm run pack`) אומת מקצה לקצה, כולל הרצת קובץ ההפעלה שנוצר.

הגרסאות הקודמות תועדו רק בהיסטוריית ה-git (לא היה `CHANGELOG.md` עד כה). בין השינויים המשמעותיים שבוצעו (לפי הודעות commit):
