# SPEC.md — אפיון הפרויקט

## מטרת הפרויקט
"לוח טהרה" היא אפליקציה (אתר סטטי + תוכנת דסקטופ Electron) לחישוב וניהול ימי טהרת המשפחה על פי ההלכה: מעקב אחרי ראיות (וסתות), חישוב עונות פרישה (עונה בינונית, יום החודש, הפלגה, ואופציונלית "אור זרוע"), מעקב הפסק טהרה, שבעה נקיים וצפי טבילה — הכול על גבי לוח שנה עברי מלא.

## הבעיה שהפרויקט פותר
מעקב ידני אחרי הלכות טהרת המשפחה (זמני פרישה, ספירת שבעה נקיים, תאריכי טבילה) מורכב וטעויות בו עלולות להיות בעלות משמעות הלכתית. האפליקציה מבצעת את החישובים ההלכתיים-לוחיים באופן אוטומטי על גבי תאריך עברי, ומציגה אותם בלוח שנה ברור.

## משתמשים מיועדים
משתמשות/משתמשים פרטיים השומרים טהרת המשפחה, המעוניינים ביומן דיגיטלי פרטי (לא מקוון, ללא שרת חיצוני) לתיעוד ומעקב.

## דרישות פונקציונליות (קיימות ופעילות)
- לוח שנה עברי (חודשי + שנתי) עם ניווט, קפיצה לחודש/שנה, וחזרה ל"היום".
- הזנת אירועים ליום: תחילת ראייה (עונת יום/לילה), הפסק טהרה, טבילה, הערה אישית.
- מנוע חישוב אוטומטי (`js/calculations.js`) המחשב:
  - עונה בינונית (יום 30 מהראייה).
  - יום החודש (אותו תאריך עברי בחודש הבא, אם קיים).
  - עונת הפלגה (לפי המרווח בין שתי ראיות אחרונות).
  - עונת "אור זרוע" (אופציונלי, עונה אחת לפני כל עונת פרישה רגילה).
  - שבעה נקיים וצפי טבילה לאחר הפסק טהרה, כולל ביטול אוטומטי אם היה אירוע מפריע בטווח.
  - אזהרה (לא חסימה) בשמירת הפסק טהרה שנעשה פחות מ-4 ימים מהראייה.
- טבלת ריכוז וסתות ותאריכי פרישה.
- לוח בקרה (Dashboard) המציג את מצב המחזור הנוכחי בזמן אמת.
- ייצוא/הדפסה של הלוח והטבלה (`window.print`).
- שליחת נתונים למייל באמצעות שירות חיצוני (FormSubmit), עם אימות חד-פעמי לכתובת חדשה.
- נעילת אפליקציה בקוד גישה (PIN בן 6 ספרות), כולל שחזור קוד באמצעות אימייל (Google Apps Script חיצוני).
- גיבוי/שחזור נתונים כקובץ JSON מקומי.
- מצב עיצוב בהיר/כהה (Theme).
- תמיכה מלאה RTL בעברית, כולל תצוגת מובייל (תפריט תחתון) ותצוגת דסקטופ (סרגל צד).
- PWA: מניפסט דינמי מוזרק בזמן ריצה (`js/app.js`).
- תוכנת דסקטופ (Electron): אותו קוד רץ בתוך חלון Electron, עם הצפנת ה-PIN באמצעות `safeStorage` של המערכת דרך IPC מאובטח (`contextBridge`/`preload.js`).

## דרישות לא-פונקציונליות
- **פרטיות**: כל הנתונים (אירועים, הערות) נשמרים אך ורק ב-`localStorage` המקומי. שום נתון אישי לא נשלח לשרת, למעט שליחה יזומה של המשתמש למייל, ומעקב סיסמה/אימייל לשחזור (רק אם המשתמש בחר להגדיר אימייל שחזור).
- **RTL / עברית מלאה** בכל הממשק.
- **תמיכה בדפדפן וב-Electron** מאותו בסיס קוד (`index.html` + `js/*` מודולים).
- **ללא תלות בבנייה (build step)**: קבצי ה-JS הם ES Modules טעונים ישירות בדפדפן (`<script type="module">`), ללא bundler.

## ממשק המשתמש
- דסקטופ: סרגל צד קבוע עם ניווט טאבים, בקרות לוח שנה, וכפתורי פעולה מהירים (עיצוב, הדפסה, מייל).
- מובייל: תפריט תחתון (Bottom Nav) + פס בקרות עליון לניווט חודשים.
- 4 מסכים עיקריים: לוח שנה, ריכוז וסתות, אודות, הגדרות.
- מודלים: פעולות יום, התראת מערכת, אישור/אזהרה, שליחת מייל, אימות מייל ראשוני, מחיקת כל הנתונים.

## זרימות עבודה מרכזיות
1. **הגדרה ראשונית**: משתמש חדש מגדיר קוד PIN (+ אימייל שחזור אופציונלי) במסך ה-Setup.
2. **כניסה יומיומית**: מסך נעילה דורש PIN; אפשרות "שכחתי קוד גישה" שולחת בקשת שחזור לשרת Google Apps Script.
3. **תיעוד ראייה**: לחיצה על יום → "תחילת ראייה" (יום/לילה) → המערכת מחשבת אוטומטית ומציגה את כל עונות הפרישה העתידיות.
4. **הפסק טהרה וטבילה**: תיעוד הפסק → המערכת מסמנת שבעה נקיים וצפי טבילה; ניתן לתעד טבילה בפועל שדוחה את הצפי.
5. **ייצוא**: הדפסת הלוח/טבלה, או שליחתם למייל נבחר.
6. **גיבוי**: הורדת/טעינת קובץ JSON.

## מגבלות ידועות
- שירותי המייל (FormSubmit) ושחזור הסיסמה (Google Apps Script) הם שירותי צד שלישי חיצוניים בבעלות המפתח — תלות ברשת ובזמינות השירות.
- הצפנת ה-PIN (`safeStorage`) פעילה רק בגרסת Electron; בגרסת הדפדפן ה-PIN נשמר כטקסט רגיל ב-`localStorage` (מוגבל להיקף האבטחה של הדפדפן/המכשיר בלבד).
- אין סנכרון בין מכשירים — כל מכשיר/דפדפן מנהל עותק נתונים נפרד (הגיבוי/שחזור הידני הוא מנגנון ההעברה בין מכשירים).

## אינטגרציות
- **FormSubmit.co** — שליחת נתוני ריכוז וסתות למייל.
- **Google Apps Script Web App** — שמירה/שחזור זוג (אימייל, PIN) לצורך שכחתי-סיסמה.
- **Google Fonts (Rubik)** — טעינת פונט מרשת.

## טכנולוגיות מרכזיות
- Vanilla JavaScript (ES Modules), HTML5, CSS3 (ללא framework, ללא bundler).
- ספריית `hebcal.js` (Hebcal) מוטמעת מקומית לחישובי לוח שנה עברי.
- Electron 25 + electron-builder 24 לאריזת תוכנת דסקטופ ל-Windows (NSIS + portable).

## קריטריוני הצלחה
- כל הפעולות מה-UI פועלות ללא שגיאות קונסול, בדפדפן ובתוכנת הדסקטופ כאחד.
- חישובי ההלכה (עונות פרישה, נקיים, טבילה) תואמים למנוע ב-`calculations.js` ונבדקו ידנית מול תרחיש מלא (ראייה → הפסק → נקיים → טבילה).
- אריזת Electron (`npm run pack` / `npm run dist`) מייצרת קובץ הפעלה תקין עם כל הנכסים (כולל אייקון).
