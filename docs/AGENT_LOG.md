## 2026-09-17 17:30 — סריקה מלאה והכשרת הפרויקט להפצה

### מטרה
לסרוק את כל הפרויקט (אתר + תוכנת דסקטופ Electron), להבין מה קיים, לזהות חלקים לא-גמורים משדרוג קודם, ולתקן באגים כדי להכין את הפרויקט להפצה מלאה.

### בוצע
1. **קריאת קוד מלאה**: `index.html`, כל 7 מודולי `js/*.js`, `css/style.css`, `hebcal.js` (API surface בלבד — ספרייה מוטמעת), `main.js`, `preload.js`, `package.json`, `.gitignore`.
2. **בדיקת wiring**: אימתתי שכל 25 הפונקציות שנקראות מ-`onclick="..."` ב-`index.html` אכן מחוברות ל-`window.*` באחד ממודולי ה-JS (אין קריאות "תלויות באוויר").
3. **בדיקת שלמות CSS**: השוואת כל `var(--x)` בקובץ ה-CSS מול ההגדרות ב-`:root`/`[data-theme="dark"]` — נמצאו 2 משתנים חסרים.
4. **בדיקה חיה בדפדפן** (Chromium דרך Browser tool, מוגש דרך `npx serve` מקומי):
   - הגדרת PIN ראשוני → הצליח.
   - נעילה מחדש + קוד שגוי → הודעת שגיאה מוצגת נכון.
   - קוד נכון → פתיחה תקינה.
   - הוספת ראייה (עונת יום) → הדשבורד והלוח מציגים "יום X מתחילת הראייה" ומסמנים עונה בינונית ביום 30 כצפוי.
   - הפסק טהרה פחות מ-5 ימים מראייה → מודל אזהרה מוצג עם הטקסט ההלכתי הנכון; אישור → 7 נקיים + צפי טבילה מסומנים נכון בלוח.
   - תצוגה שנתית → 13 שורות (שנה מעוברת תשפ״ז) × 30 תאים, ללא שגיאות.
   - מסך הגדרות: הפעלת "אור זרוע", עדכון PIN, פתיחת מודל מייל, הורדת גיבוי JSON — כולם עברו ללא שגיאת קונסול.
   - `prepareAndPrint()` → בנה נכון את תוכן ההדפסה וקרא ל-`window.print()` (אימות עצירה תקינה — לא בוצע ניסיון השלמת דיאלוג ההדפסה עצמו, זהו דיאלוג מערכת הפעלה).
   - בכל הבדיקות: `read_console_messages` החזיר "No console logs" — אין שגיאות JS.
5. **תיקוני באגים** (ראו פירוט מלא ב-[DECISIONS.md](DECISIONS.md)):
   - SVG שבור (חסר `</path>`) ב-3 מקומות.
   - 2 משתני CSS לא מוגדרים (`--shadow-lg`, `--surface-hover`).
   - `icon.png` חסר מ-`files` באריזת electron-builder.
   - הסרת 2 פונקציות stub מתות מ-`js/app.js`.
6. **אימות אריזת Electron בפועל**:
   - `npm install` (כולל אישור סקריפט postinstall של Electron דרך `npm approve-scripts electron`).
   - `npm run pack` (electron-builder --dir) — הצליח, הוריד Electron v25.9.8 win32-x64, ארז ל-`dist/win-unpacked`.
   - `asar list` על `app.asar` שנוצר — אימת שכל הקבצים כולל `icon.png` נכללים.
   - הרצת `לוח טהרה.exe` שנוצר בפועל (PowerShell `Start-Process`) — האפליקציה עלתה, נשארה רצה, וכותרת החלון הוצגה נכון ("לוח טהרת המשפחה").
   - ניקוי: תיקיית `dist/` נמחקה בסיום (תוצר build, לא אמור להיכלל ב-git — וגם ב-`.gitignore`).

## 2026-09-17 19:45 — מימוש מלא של "אפיון תוספות עתידיות מתוכננות"

### מטרה
המשתמש איתר קובץ מקומי (`אפיון תוספות עתידיות מתוכננות.txt`, לא במעקב git) עם רשימת תכונות עתידיות מתוכננות, ולאחר בדיקה שאף אחת מהן לא מומשה, ביקש: "פשוט בצע הכל. ואז תכין להפצה מלאה כל מה שצריך."

### בוצע
1. **מודול שקיעה/מיקום חדש** (`js/zmanim.js`): שימוש ב-`Location`/`Zmanim` הקיימים בתוך `hebcal.js`, עם רשימת ~65 ערים. נוספה בחירת עיר בהגדרות + הצגת שעת שקיעה.
2. **"היום" הלכתי בכל האפליקציה**: `getHalachicTodayAbs()` הוזרם דרך `refreshCalendar → renderScreenCalendar → buildMonthGridHTML/buildYearlyRowHTML/updateDashboard`, במקום `new HDate().abs()` מקומי בכל פונקציה.
3. **תיקון מיקום נקיים/טבילה**: נוסף `computed.nekiimFirstDay` ב-`calculations.js`; לוגיקת רינדור ב-`ui.js` שונתה כך שיום 1 של הנקיים וטבילה (צפי/בפועל) מוצגים בחלק העליון (לילה) של המשבצת הנכונה. **אומת בבדיקה אוטומטית מדויקת** מול הדוגמה המספרית שהמשתמש נתן (הפסק ט"ו → נקיים יום 1 ב-ט"ז, נקיים עד כ"ב, טבילה ב-כ"ג) — תוצאה תואמת ב-100%.
4. **תאריך לידה משוער**: נוסף ל-`updateDashboard` (מותנה ב-35+ יום ללא הפסק מאז ראייה אחרונה).
5. **זום גלובלי**: `document.body.style.zoom`, נשמר ב-`localStorage`, כפתורים בסרגל הצד + מובייל.
6. **כניסה אוטומטית ב-PIN**: `security.js` — לאחר כל הקלדה ב-`unlock-pin-container`, אם כל 6 השדות מלאים, נקרא `window.verifyPin()` אוטומטית.
7. **החלפת אימוג'ים ← SVG**: נסרקו כל הקבצים (regex טווחי Unicode של אימוג'י) — 0 תוצאות בסוף. תוך כדי כך נמצא ותוקן באג: `updateThemeIcon()` דרס בפועל SVG קיים באימוג'י טקסטואלי (`btn.innerText`); תוקן ל-`innerHTML` עם `ICONS.SUN/MOON`.
8. **התראות מחשב** (`js/app.js` — `checkAndFireNotification`): Web Notification API, מבוסס על אותו טקסט שכבר מוצג בדשבורד (אין לוגיקה כפולה).
9. **Electron: מגש מערכת + הפעלה אוטומטית + עדכונים** (`main.js`, `preload.js`): הוספת `Tray`, `app.setLoginItemSettings`, ואינטגרציית `electron-updater` מלאה (checking/available/downloading/downloaded/error → IPC → UI בהגדרות). הותקן `electron-updater` כ-dependency (לא devDependency) כדי שייארז בפועל.
10. **עיצוב מינימליסטי ממוקד**: מרקרים בצבע שטוח, הסרת `pulseGlow` האינסופי על "היום". תוך כדי כך נמצא ותוקן באג קיים נוסף: `.alert-pulse` נקרא מ-`ui.js` אך מעולם לא הוגדר ב-CSS.
11. **הכנה סופית להפצה**:
    - זוהה ותוקן: `icon.png` היה בפועל **JPEG** עם סיומת שגויה (חתימת בייטים `FFD8FF`, לא `89504E47`) — הומר לקובץ PNG אמיתי (1024×1024) באמצעות `nativeImage` של Electron (סקריפט חד-פעמי, לא נשאר בקוד).
    - נוצר `LICENSE` (טקסט GPL-2.0 הרשמי, נשלף דרך `gh api licenses/gpl-2.0`).
    - נכתב `README.md` מלא (קודם היה שורתיים בלבד).
    - `package.json`: גרסה 1.1.1 → 1.2.0, נוסף `build.publish` (GitHub, `Lev-Good/Purification-board` — **קונפיגורציה בלבד, לא בוצע פרסום בפועל**).
