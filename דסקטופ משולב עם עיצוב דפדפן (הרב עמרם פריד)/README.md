# לוח טהרה — גרסה משולבת דסקטופ ודפדפן (הרב עמרם פריד)

פרויקט גרסה חדשה עצמאית המשלבת ממשק משתמש בטכנולוגיות ווב (HTML5 / Modern CSS) יחד עם מנוע הלכתי מאומת ב-C# (`Taharah.Core`).

## מבנה הפרויקט
- `src/Taharah.Core/`: מנוע חישוב הדינים והווסתות לפי ספרי הרב עמרם פריד שליט"א.
- `src/Taharah.Infrastructure/`: תשתית נתונים ואבטחה מקומית.
- `tests/Taharah.Core.Tests/`: סוויטת 261 בדיקות יחידה אוטומטיות המאמתות 100% מהחישובים והאירועים.
- `mockups/`: אבות-טיפוס של עיצוב ה-Web.
- `Taharah.slnx`: קובץ ה-Solution של הפרויקט.

## הרצת בדיקות
```powershell
dotnet test Taharah.slnx
```
