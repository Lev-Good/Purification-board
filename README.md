# לוח טהרה (Purification Board)

אפליקציית חישוב ימי הטהרה ולוח שנה עברי — מנוע הלכתי מבוסס מקורות (ספר "שיעורי טהרה") לחישוב עונות פרישה, זיהוי וסת קבוע, עקירת וסת, מצבי חיים הפוטרים מחשש (הריון/הנקה/זקנה/כדורים), וכל דיני הטהרה הנלווים — על גבי לוח שנה עברי מלא. זמינה כאתר (דפדפן/PWA) וכתוכנת דסקטופ ל-Windows (Electron).

כל הנתונים נשמרים אך ורק על המכשיר המקומי, מוצפנים. שום נתון אישי לא נשלח לשרת חיצוני מלבד גיבוי יזום לגוגל דרייב (אופציונלי, בחיבור OAuth של המשתמש עצמו).

## תכונות עיקריות

- **מנוע הלכתי מקורי**, כל חוק מגובה במראה מקום מדויק (שיעור ועמוד) — ראו `docs/SPEC_DINIM_VESATOT.md`.
- זיהוי וסת קבוע (חזקה), עקירת וסת, וסת דילוג, וסת גוף/מיחוש.
- מצב חיים: פטור מחשש למעוברת, מניקה, זקנה, קטנה, ודיני נטילת/הפסקת כדורים.
- מחלוקות פוסקים מוצגות כמחלוקת מפורשת (מתגי חומרא), לא מוכרעות בשקט.
- לוח שנה עברי (חודשי ושנתי), טבלת ריכוז וסתות, בועות הסבר לכל דין.
- נעילת אפליקציה בקוד גישה (PIN) מוצפן מקומית.
- גיבוי/שחזור נתונים כקובץ JSON, וגיבוי אוטומטי לגוגל דרייב (OAuth מובנה, ללא הגדרה מצד המשתמש).
- מצב עיצוב בהיר/כהה, תמיכת RTL מלאה בעברית.
- מערך בדיקות אוטומטיות מקיף (`npm test`) וכלי אימות מראי מקום (`npm run verify:sources`).

## הרצה כאתר

פתחו את `index.html` בדפדפן — אין שלב build, כל קבצי ה-JS הם ES Modules הנטענים ישירות.

## הרצת תוכנת הדסקטופ (פיתוח)

```bash
npm install
npm start
```

## בדיקות

```bash
npm test
```

## בניית קובץ התקנה (Windows)

```bash
npm run dist
```

יוצר בתיקיית `dist/` גם מתקין NSIS וגם גרסה Portable.

## תיעוד

תיעוד מלא של הפרויקט (אפיון הלכתי, ארכיטקטורה, החלטות, משימות, יומן עבודה) נמצא בתיקיית [`docs/`](docs/). ראו במיוחד `docs/SPEC_DINIM_VESATOT.md` (האפיון ההלכתי המלא) ו-`docs/RABBI_QUESTIONS.md` (שאלות פתוחות לבירור עם פוסק).
