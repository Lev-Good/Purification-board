# לוח טהרה (Purification Board)

אפליקציית חישוב ימי הטהרה ולוח שנה עברי — עוזרת למעקב אחר וסתות, עונות פרישה, שבעה נקיים וטבילה, על גבי לוח שנה עברי מלא. זמינה כאתר (דפדפן/PWA) וכתוכנת דסקטופ ל-Windows (Electron).

כל הנתונים נשמרים אך ורק על המכשיר המקומי — שום מידע אישי לא נשלח לשרת חיצוני (מלבד שליחת מייל/שחזור קוד גישה, כאשר המשתמש בוחר להפעיל זאת במפורש).

## תכונות עיקריות

- לוח שנה עברי (תצוגה חודשית ושנתית) עם ניווט מלא וזום תצוגה.
- מנוע חישוב אוטומטי: עונה בינונית, יום החודש, עונת הפלגה, "אור זרוע" (אופציונלי), שבעה נקיים וצפי טבילה.
- חישוב היום ההלכתי לפי שקיעה (לפי עיר נבחרת), לא רק לפי חצות לועזי.
- חישוב תאריך לידה משוער (הערכה גסה, לא תחליף לייעוץ רפואי).
- נעילת אפליקציה בקוד גישה (PIN), כולל שחזור קוד באמצעות אימייל.
- התראות מחשב/דפדפן (יומיות או רק בימי אירוע).
- גיבוי/שחזור נתונים כקובץ JSON מקומי, הדפסה, ושליחת נתונים למייל.
- מצב עיצוב בהיר/כהה, תמיכת RTL מלאה בעברית.
- תוכנת דסקטופ עם הצפנת קוד גישה מקומית, מגש מערכת, הפעלה אוטומטית, ובדיקת עדכונים אוטומטית מול GitHub Releases.

## הרצה כאתר

פתחו את `index.html` בדפדפן (או הגישו את התיקייה כשרת סטטי) — אין שלב build, כל קבצי ה-JS הם ES Modules הנטענים ישירות.

## הרצת תוכנת הדסקטופ (פיתוח)

```bash
npm install
npm start
```

## בניית קובץ התקנה (Windows)

```bash
npm run dist
```

יוצר בתיקיית `dist/` גם מתקין NSIS וגם גרסה Portable.
