## 2. מה נבדק מבלי לבצע ⏸ — בניית המתקין והעלאה ל-GitHub

העבודה על המתקין הופסקה לפני הבנייה. ממצאי הבדיקה המקדימה (חשובים להמשך):

### מבנה פרויקט המתקין (`src/Taharah.Installer/`, אינו כלול ב-Taharah.slnx)
- `AssemblyName = התקנת_לוח_טהרה` — פלט ה-publish הוא בדיוק השם המבוקש.
- `TargetFramework: net10.0-windows`, WPF, גרסה 3.4.1 (עודכן).
- **מטמיע כ-payload את ה-zip של הגרסה הניידת** (`EmbeddedResource` → `../../קבצי הפצה/גרסה ניידת/לוח_טהרה_גרסה_ניידת.zip`) + אייקון. ה-zip המוטמע כבר מעודכן ל-3.4.1.
- ההתקנה בפועל: חילוץ ה-payload לתיקיית יעד `%LocalAppData%\Programs\Taharah`, קיצורי דרך, וכתיבת מפתח Uninstall עם `DisplayVersion = "3.4.1"`.
- **המתקין הקיים** (`קבצי הפצה/גרסת התקנה/התקנת_לוח_טהרה.exe`, מ-29/09): **222,282,889 בייט (~222MB)** + pdb. כלומר נבנה כ-self-contained single-file עם ה-payload המוטמע.

### מצב git (שורש הפרויקט, branch `main`)
- **תיקיית הפרויקט המשולב כולה לא מנוטרת** (`??`) — מעולם לא נוספה למאגר.
- origin = `https://github.com/Lev-Good/Purification-board.git` (מאגר פרטי).
- `.gitignore` קיים ומתאים: `**/dist/`, `**/bin/`, `**/obj/`, `*.log` מושמטים; `קבצי הפצה/` אינו מושמט.
- קבצים שאינם בעבודה שלנו ויש להשאיר מחוץ ל-commit: השינויים ב-`תוכנת דסקטופ (CSharp)/*`, `temp_releases/`, `thread-*.md`.

### מגבלה קריטית שזוהתה
- **המתקין (~222MB) חורג ממגבלת ה-100MB של GitHub לקובץ בודד ב-git** — אי אפשר לדחוף אותו למאגר. הערוץ הנכון לו הוא **asset של GitHub Release** (עד 2GB ל-asset).
- על פי ה-README והיסטוריית ה-commits, ההפצות הציבוריות נמצאות במאגר `Lev-Good/Purification-board-releases` (**טרם אומת בפועל מול GitHub**).
- `gh` CLI מותקן (2.89.0) **ומאומת** כ-Lev-Good עם scope `repo` — מאפשר push ויצירת Release.

## 3. תוכנית ההמשך (לא בוצעה)

1. **בניית המתקין** (self-contained single-file, בדומה לקודם):
   `dotnet publish src/Taharah.Installer/Taharah.Installer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true`
   (לוודא שה-payload המוטמע הוא ה-zip החדש 3.4.1; אימות FileVersion של ה-exe = 3.4.1).
2. **החלפת** `קבצי הפצה/גרסת התקנה/התקנת_לוח_טהרה.exe` (+pdb) בפלט החדש.
3. **`.gitignore`:** הוספת המתקין (>100MB) מהמעקב, למשל `**/קבצי הפצה/גרסת התקנה/`.
4. **עדכון תיעוד** (טרם בוצע גם עבור סבב 3.4.1 עצמו — ראה סעיף 4): CHANGELOG (כותרת הרשומה עדיין "סבב תיקון ל-3.4.0" והערת "המתקין לא נבנה" שהתיישנה), AGENT_LOG, TASKS.
5. **Commit + push** ל-origin: תיקיית הפרויקט המשולב (ללא dist/bin/obj — מושמטים כבר) + `תיעוד הפרויקט/`. להשאיר מחוץ ל-commit את השינויים ב-`תוכנת דסקטופ (CSharp)/*`, `temp_releases/`, `thread-*.md`.
6. **GitHub Release v3.4.1** במאגר ההפצות הציבורי (לאמת קיומו קודם): assets = המתקין החדש + ה-zip הנייד, עם הערות בעברית.
7. **בעיה פתוחה מוכרת (מחוץ להיקף כרגע):** בדיקת העדכונים בתוך התוכנה שולחת בקשה למאגר הפרטי `Purification-board` ולכן תמיד נכשלת (404) — כדאי להפנות למאגר ההפצות הציבורי בסבב עתידי (דורש בניית הפצה מחדש מלאה).
